## ⚡ Quick Actions

**Search Books**:
1. Go to Books page
2. Type in search field
3. See results update in real-time

**Filter by Author**:
1. Go to Books page
2. Enter author ID
3. Use +/- buttons to adjust

**Add Author**:
1. Go to Authors page
2. Click + Add New Author
3. Enter unique ID and Name
4. Click ✅ Add Author

**Create Book**:
1. Go to Create Book page
2. Fill Title, Pages, Publisher
3. Select Author (must exist!)
4. Add Tags (optional)
5. Click ✨ Create Book

**View Stats**:
1. Go to Publishers page
2. Select publisher from dropdown
3. View metrics and book list
